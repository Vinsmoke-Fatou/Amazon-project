# Amazon Mockup – Responsive E-Commerce Platform

## Overview
This project is a partial clone of the Amazon e-commerce platform. It is a dynamic and responsive website designed to replicate the user interface, navigation, and checkout flow of a modern online store, with a strong focus on client-side interactivity.

## Features

- Catalog and Product Display:
  _Presentation of items in a modern grid layouts with images, descriptions, ratings, and prices.
  _Fluid responsive layout adapting to all screen sizes (desktop, tablet, mobile).

- Dynamic Cart Management:
  _Real-time addition and removal of items.
  _Automatic updates of the global item quantity displayed in the navigation header.
  _Instant calculation of the cart's total price.

- Checkout Validation Process:
  _Dedicated page for reviewing purchases (Checkout).
  _Input forms for delivery and payment information.
  _Smooth user flow guiding the customer from product selection to the final purchase simulation.

## Project Architecture

The project is structured around standard web files integrating the core application logic:

Amazon-project/
├── data/              # Product data files and configurations
├── images/            # Visual assets and platform logos
├── checkout.html      # Review and cart validation page
├── index.html         # Main homepage and product catalog
├── amazon.js          # Core site logic and event handling
├── checkout.js        # Script handling cart operations and totals
└── ...
